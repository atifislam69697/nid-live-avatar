# NID Live Avatar

NID বা যেকোনো ছবি থেকে লাইভনেস-ধাঁচের অ্যানিমেটেড ভিডিও (MP4) তৈরি করে — মৃদু মাথার নড়াচড়া, স্কেল-ব্রিদিং ও চোখের পলকসহ।

ভিডিওটি ভার্চুয়াল ক্যামেরা মডিউলের (যেমন xCam, CamSwap, DRVCAM) সোর্স হিসেবে ব্যবহার করা যায়।

## ব্যবহার
1. ছবি বাছুন (NID/পাসপোর্ট ফটো)
2. "লাইভ ভিডিও বানান" চাপুন — ৮ সেকেন্ডের 720x1280 MP4 তৈরি হবে
3. ভিডিও সেভ হয় Movies/NIDLiveAvatar ফোল্ডারে

প্রয়োজনীয় পরিবেশ: রুটেড ফোন + Zygisk/LSPosed + ভার্চুয়াল ক্যামেরা মডিউল।

## প্রযুক্তি
Kotlin, ML Kit Face Detection, MediaCodec (H.264) + MediaMuxer। ইন্টারনেট লাগে না।
